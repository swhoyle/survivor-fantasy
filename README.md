# Survivor Fantasy

Web application to view and analyze Survivor Fantasy data for a Bracketology league.

Website: https://swhoyle.github.io/survivor-fantasy/


### Technologies
- Scraped and parsed Bracketology data using Python and Playwright.
- Stored data in Google Sheets with Google API and made it avialable publicly.
- Built a React application front end.
- Automated data refresh with Github actions, scheduled every Thursday at 3:00 AM PST.
